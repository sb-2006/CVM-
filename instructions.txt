  CVM++ — Instructions to Build and Run the Compiler + VM
================================================================

PROJECT: CVM++ (Custom Virtual Machine & Scripting Language)
LANGUAGE: C++17
MENTOR: Raman

----------------------------------------------------------------
WHAT THIS PROJECT IS
----------------------------------------------------------------
CVM++ is a full compiler + virtual machine built in C++.
You write a .cvm script, it gets compiled to bytecode, and
the bytecode runs on our custom stack-based Virtual Machine.

Pipeline:  .cvm source → Lexer → Parser (AST) → Compiler
           (Bytecode) → Virtual Machine → Output

----------------------------------------------------------------
OPTION A: USE THE PRE-BUILT BINARY (Windows, no setup needed)
----------------------------------------------------------------
A pre-built Windows executable is included: cvm.exe

Step 1. Open Command Prompt or PowerShell in the project folder.

Step 2. Run any .cvm script:
        cvm.exe samples\calculator.cvm
        cvm.exe samples\truth_machine.cvm
        cvm.exe samples\fibonacci.cvm
        cvm.exe test.cvm

Step 3. To see the generated AST (debug mode):
        cvm.exe samples\calculator.cvm --ast

Step 4. To see the compiled Bytecode before execution:
        cvm.exe samples\calculator.cvm --bytecode

Step 5. To see both AST and Bytecode:
        cvm.exe samples\calculator.cvm --ast --bytecode

----------------------------------------------------------------
OPTION B: BUILD FROM SOURCE (Linux / macOS / Windows)
----------------------------------------------------------------

REQUIREMENTS:
  - GCC, Clang, or MSVC with C++17 support
  - No external libraries needed

Step 1. Clone or download the repository.

Step 2. Open a terminal in the project root directory.

Step 3. Compile:

  Linux / macOS:
    g++ -std=c++17 -Iinclude src/*.cpp -o cvm

  Windows (MinGW / Git Bash):
    g++ -std=c++17 -Iinclude src/*.cpp -o cvm.exe

  Windows (MSVC Developer Command Prompt):
    cl /std:c++17 /I include src\*.cpp /Fe:cvm.exe

Step 4. Run a script:

  Linux / macOS:
    ./cvm samples/calculator.cvm
    ./cvm samples/calculator.cvm --bytecode

  Windows:
    cvm.exe samples\calculator.cvm
    cvm.exe samples\calculator.cvm --bytecode

----------------------------------------------------------------
WRITING YOUR OWN .CVM PROGRAMS
----------------------------------------------------------------
Create a file called myscript.cvm and use this syntax:

  let x = 10;            // declare variable
  let y = input;         // read from keyboard
  print x;               // print to terminal

  if (x < 5) {
      print 1;
  } else {
      print 0;
  }

  while (x > 0) {
      x = x - 1;
      print x;
  }

  fn square(n) {
      return n * n;
  }
  print square(7);       // prints: 49

Then run:  ./cvm myscript.cvm
